# Lantern
Lantern is a tiny command-line task tracker written in Python 3 (standard library only).
## Install and usage
(code block)
git clone https://github.com/<A-user>/lantern.git
cd lantern
python lantern.py add "write report"
python lantern.py list
(end code block)
## Commands
- `add <title>`: add a task
- `list [--done] [--sort]`: show tasks
- `export --csv`: print tasks as CSV
See [usage docs](docs/usage.md) for details. See [CONTRIBUTING.md](CONTRIBUTING.md).
